Want to inspect network activity or endpoints of a closed source binary or script that you don't understand? Try following on Linux:
```
strace -f -e trace=network -o /tmp/network_trace.txt /opt/foo.bin

strace -f -e trace=network -o /tmp/network_trace.txt python3 /path/to/bar.py
```
Then you can view all network it made:
```
less /tmp/network_trace.txt
```

strace is nifty diagnostic, debugging, and instructional userspace utility for IT, cybersecurity or dev folks. See:
```
man strace
```
